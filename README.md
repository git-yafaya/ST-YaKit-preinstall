# ST-YaKit-preinstall

YaKit 系列的 SillyTavern 提示词工作台，用场景试写和 AI 盲评帮助你生成、筛选和改进提示词。

## 功能特性

- 按需求生成独立提示词，支持继续修改、自动保留旧稿和多版本管理。
- 从导航栏首项「预设预览」预览、开关和编辑预设条目，复制完整预设，搭配测试版本并随时恢复原版。
- 手填或由 AI 生成冲突场景，默认无需角色卡，同时生成三份正文样本；样本数可选一至六份。
- AI 按原始需求盲评并排名，列出问题原句、对应要求和理由，区分明确违例与疑点。
- 选择最喜欢的样本，引用片段、保存反馈并据此修改提示词；失败后可重新盲评已有样本。
- 为提示词、场景、正文和裁判分别选择副 API，留空时沿用酒馆当前 API；支持复用酒馆连接、保存多套配置和合并生成，配置页底部常驻操作按钮。
- 在「设置 → 内置提示词」集中调整破限、补充、场景生成、裁判、反馈修订和聊天试写的引导；破限提示词默认提供叙事初始化文案。
- 四种主题可选，默认林系风；支持电脑与手机自适应布局，五页共用窗口尺寸和动效；滚动条显隐时内容宽度保持稳定，文本输入框聚焦时不显示外圈高亮。
- 自动保存需求、草稿和已提交记录，支持复制提示词、导出工作记录及独立本地演示。

## 安装方法

装好后可以完成「生成提示词 → 固定场景 → 三份样本 → AI 盲评 → 选择最喜欢的结果」；首次使用请先连接酒馆 API，或配置副 API。

1. 将完整项目文件夹放入 SillyTavern 的 `public/scripts/extensions/third-party/` 目录，保留文件夹内的目录结构。
2. 刷新 SillyTavern，从扩展菜单点击「工作台」；默认空卡模式无需打开角色或群组聊天。
3. 副 API 留空即可使用酒馆当前 API；需要其他连接时，在「设置 → 副 API」保存配置，各环节默认沿用，也可在「模块 API」单独选择。
4. 回到「工作台」，填写需求并点击「生成提示词」，将草稿「保存为版本」。
5. 进入「试写与反馈」，填写场景或选择 AI 场景，点击「创建测试任务」，等待三份样本及评分，再选择最喜欢的结果。

### 本地演示

无需连接模型，即可用内置示例体验完整流程。

1. 在项目文件夹内启动静态服务，例如已安装 Python 时运行 `python3 -m http.server 8000`。
2. 打开[本地演示入口](http://127.0.0.1:8000/preview.html)，填写需求、保存版本并试写。
3. 阅读带有「本地演示」说明的示例正文，再提交反馈；演示记录保存在当前浏览器中，与酒馆记录分开。

## 使用说明

1. **描述需求。** 填写「你希望改善什么？」和本次要求，点击「生成提示词」。新要求默认生成独立条目；要修改当前条目，请明确写出修改内容。
2. **编辑并保存。** 修改草稿，填写提示词名称并点击「保存为版本」；名称选填，继续保存会新增版本。旧稿可在「版本记录」选择。
3. **创建测试。** 在原始需求框写全评分要求，进入「试写与反馈」，填写或生成场景，点击「创建测试任务」。样本生成后自动盲评；草稿改过后需先保存新版本。
4. **筛选并反馈。** 核对需求清单、排名和审查依据，点击「选为最喜欢」，选择「达到预期」或「还需修改」并填写反馈。可选中正文点击「引用选中正文」，再「保存反馈」。
5. **按反馈修改。** 点击「按反馈修改」，围绕本次试写的版本生成新草稿。有引用时使用片段，未引用时使用完整正文；回工作台保存新版本后继续测试。
6. **保存成果。** 在工作台「复制提示词」，或在版本记录「导出工作记录」。已提交内容自动保存，导出不包含副 API 密钥。

生成过程中可点击「取消」，已有内容会保留。酒馆 API 请求可能仍需等待模型结束后才能再次发起；生成期间手动编辑的草稿不会被返回的建议覆盖。

生成结果替换草稿前，尚未保存过的原文会自动留在「版本记录」，已保存过的相同原文不重复留存。要修改以前的条目，先在版本记录选择它，再回工作台说明修改要求。

### 场景与样本测试

1. **选择场景。** 「手动填写」使用你输入的文本，不能留空；「AI 生成冲突场景」可先点击「生成冲突场景」再编辑，也可留空，在创建任务时生成。已有场景会沿用，方便不同版本复测同一条件。
2. **选择背景。** 「空卡模式」默认开启，只使用提示词和场景；关闭后使用当前聊天背景，需打开角色或群组，并让正文沿用酒馆当前 API（副 API 留空）。
3. **选择样本数量。** 默认三份，可选一至六份。空卡模式同时发起各份独立请求，每份使用相同提示词和固定场景，彼此不看其他样本；关闭空卡后的当前聊天试写逐次生成。
4. **选择单次生成。** 接口支持时，可选「单次请求返回 n 个样本」。接口必须实际返回所选数量；不支持时改用独立请求。文本补全和关闭空卡后的聊天试写使用独立请求。
5. **查看结果。** 裁判按原始需求、固定场景和匿名正文评分；补充要求需写入原始需求框。分数为零至一百分，允许并列；明确禁令优先，违例先看影响程度再看次数，疑点不直接按违规扣分。默认先显示最高分样本，可展开任务快照核对条件。
6. **继续筛选。** 切换任务可看历史结果；旧版记录位于「历史单次试写」。裁判失败可「重新盲评现有样本」，正文和人工反馈继续保留；只生成部分样本时会明确标出数量。重评不会代替你的「最喜欢」选择。

### 管理提示词记录

1. 进入「版本记录」，选择要复测的提示词；页面显示它的名称、版本号、保存时间和原文，再通过常驻导航进入「试写与反馈」创建测试。
2. 要改名时，编辑「提示词名称」并点击「保存名称」；名称会同步显示在工作台和对应的试写记录中，原文保持不变。
3. 要删除时，点击「删除提示词」，核对提示词名称、版本号及关联试写数量，再点击「确认删除」；也可点击「取消」保留记录。
4. 删除会同时移除该版本的测试任务、试写、评分和反馈，当前草稿继续保留。其余版本号保持不变，新保存的版本继续递增。

### 预览与搭配预设条目

1. 点击导航栏第一项「预设预览」（第二项为「工作台」），读取酒馆当前已保存的聊天补全预设，也可在列表中选择其他预设。
2. 想保留副本时，点击「复制预设」，复制当前预设已保存的全部内容，并在工作台和酒馆中切换到副本。名称从「原名-试作1」开始，接着当前最大试作编号递增；复制试作副本时继续沿用原名编号。需要带入本次编辑时，先保存对应条目。
3. 点击条目旁的「已开启／已关闭」按钮切换并保存状态；无需展开条目，酒馆允许切换的标记条目也可操作。
4. 展开条目，在来源列表选择「原版提示词」或已保存的测试版本；先查看正文，再点击「应用提示词」。各条目分别选择、分别应用，即可自由搭配；要在聊天中生效，还需开启该条目。需要新的测试提示词时，先在工作台「保存为版本」。
5. 想恢复时，选择「原版提示词」并应用。原文在首次应用测试版本时保留，刷新页面或删除测试版本后仍可恢复。
6. 原版正文可直接修改并「保存条目」；有未保存编辑时，先保存再应用其他版本。手动保存的正文会成为新的原版。点击「载入草稿」使用该条目当前已保存的正文，明确说明要修改当前条目后，可「保存到原条目」。
7. 点击「重新读取」更新内容，点击「刷新列表」更新可选预设。切页、切换预设和重新读取保留本次未保存编辑；刷新酒馆页面前请逐条保存。

应用与保存正文保留名称、角色、开关和原有位置；开关操作只改启用状态，首次开启未加入顺序的条目时，会按酒馆规则放到顺序开头。应用到当前预设会同步酒馆正常聊天，应用到其他预设不会切换当前选择。标记条目的正文由酒馆提供，不能替换或编辑。

若提示原文或开关已变化，先处理并保存酒馆中的改动，再「重新读取」。在「版本记录」选择旧版本或重新读取预设后，需要重新载入条目才能从草稿写回。

新生成的独立提示词保存在工作台中，可分别复制到酒馆预设。生成新条目或按试写反馈修订后，会解除原来的预设写回目标；目前工作台不提供新增酒馆预设条目的入口。

### 调整界面与退出

1. 打开「设置」，展开「界面设置」。
2. 默认使用林系风，已有主题选择继续保留；可选择林系风、浅色、深色或跟随酒馆，五页立即同步并保存。
3. 导航选择「自动」时，PC 端显示上方文字，手机和平板显示下方图标；也可固定为「上方」或「下方」。
4. 点击页签切换页面；手机下拉列表可再次点击选择框收起，各页支持滚轮、触屏或键盘滚动。
5. 点击关闭按钮、窗口外的遮罩或按 Esc 退出；重开保留输入，未确认的设置草稿会丢弃。

### 配置 API 与提示词

1. 打开「设置」，展开「副 API」，点击「使用配置」右侧的「配置 API」新建连接。
2. 选择酒馆的「连接配置文件」自动填写信息；保存时未包含 API 类型的连接会沿用酒馆当前类型。也可填写配置名称、Base url、API-Key 和模型名称，点击「拉取模型」后从列表选择。
3. 点击页面底部右侧「保存」后使用该副 API；底部左侧「返回」放弃本次编辑，编辑已有配置时可点击同侧「删除」。在「使用配置」中切换，点击下方配置卡片可编辑；将选择留空即可沿用酒馆当前 API，已保存的配置会保留。
4. 展开「模块 API」，分别为提示词、冲突场景、正文样本和盲评选择已保存配置或沿用副 API；默认全部沿用，未填写副 API 时使用酒馆当前 API。
5. 需要提示词和场景同时生成时，先在试写页选择 AI 场景，再为这两个环节选同一连接，开启「生成提示词时，一次请求同时生成冲突场景」。手填场景会继续保留。
6. 展开「内置提示词」，选择破限、补充、场景生成、裁判、反馈修订或聊天试写提示词，编辑后点击顶栏「确认」。每项只用于对应环节，已开始的任务继续使用开始时的内容；重新盲评使用最新保存的裁判提示词。
7. 提示词偏离默认内容时显示「已修改」；点击「重置」只恢复编辑框的默认内容，确认后保存。已有保存内容时，可在破限提示词中按此操作应用新的叙事初始化文案。返回、切换页面或关闭会放弃本次未确认的设置编辑。

读取酒馆连接完成后才能保存。酒馆不允许显示已保存密钥时，仍可复用该连接；填写自己的 API-Key 后可修改 Base url。正文样本使用「模块 API」中选择的连接；副 API 正文需要开启空卡模式。

## 兼容性

最低支持 **SillyTavern 1.18.0**：依赖该版本的独立请求、静默生成、连接和预设管理接口。

支持自定义下拉样式的浏览器会显示统一配色、可换行的选项弹层，优先向下展开，下方放不下时自动调整方向；其他浏览器使用系统下拉菜单，外观和展开方向由浏览器和系统决定。

## 常见问题（FAQ）

**为什么试写按钮不可用？**

先填写原始需求并保存提示词版本；草稿与已保存版本不一致时需要另存新版本。空卡模式无需角色卡；关闭空卡时，需要打开角色或群组，并让正文沿用已连接的酒馆 API。副 API 可在设置中统一选择，也可为各环节单独选择。

**为什么场景还在沿用聊天内容？**

在试写页打开「空卡模式」，正文请求只包含测试提示词和固定场景；关闭空卡时会继续加载当前聊天背景。可展开任务快照核对真正使用的场景。

**单次生成提示接口没有返回足够样本怎么办？**

将「样本请求方式」改为「独立请求」；该接口可能不支持一次返回多份结果。已生成的其他任务与评分会保留。

**试写会直接发到聊天里吗？**

试写正文显示在工作台，不会自动作为聊天消息发送。

**为什么点击取消后仍提示酒馆 API 忙碌？**

关闭空卡后的聊天试写使用酒馆静默生成，取消后仍可能需要等待它结束；空卡独立请求会发送取消信号，工作台保留已收到的样本并忽略迟到结果。

**保存失败怎么办？**

先点击「导出工作记录」留存当前内容，确认下载完成后再关闭。未提交的反馈和设置仍需先保存。

**能导入记录或直接写回预设吗？**

可以在「预设预览」展开条目并点击「保存条目」写回，也可选择测试版本后「应用提示词」，或载入草稿修改后「保存到原条目」；工作记录支持导出，暂不支持导入。

**预设条目保存后会切换当前预设吗？**

不会。保存到当前使用的预设时，对应条目也会同步到酒馆；保存到其他预设时，当前选择保持不变。若目标条目已在酒馆中修改，请先处理那里的改动，再重新读取。

**为什么某些条目不能编辑？**

世界书、聊天记录等标记条目由酒馆填充，不提供正文编辑。目前读取已保存的 Chat Completion 预设；本地演示不连接酒馆预设。
