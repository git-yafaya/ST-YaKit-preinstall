# ST-YaKit-preinstall

YaKit 系列的提示词工作台，帮助你走完「描述需求 → 编辑提示词 → 试写 → 人工反馈 → 保留下一版」的流程。

当前提供 **v0.1.0 独立交互预览**，用于体验和确认操作流程，尚未作为正式版本发布。页面中的 AI 操作使用本地预置的「NPC 认知边界」提示词与正文；更换需求、场景或意见会保留你的输入，示例回复仍来自这组固定内容。

## 功能特性

- 描述期望效果，查看示例讨论，也能直接编辑提示词草稿。
- 为提示词保存多个版本，切换查看；每次试写保留所用版本。
- 阅读示例正文，标记「达到预期」或「还需修改」，引用原文并填写意见。
- 按选定试写的反馈继续修改，保留旧版提示词和已有反馈。
- 复制当前草稿、导出工作记录，并在当前浏览器中自动保存已提交的内容。

## 安装方法

拿到文件后即可体验一次完整的提示词修改流程，无需填写模型配置。

1. 将整个项目文件夹保存到本机，保留其中的文件和子文件夹。
2. 用浏览器打开 `index.html`，查看已填好的示例需求。
3. 点击「生成示例提示词」，阅读或编辑草稿，再点击「保存为版本」。
4. 点击「试写选中版本」，阅读正文，选择评价并填写意见，点击「按反馈修改」。
5. 将下一版保存并再次试写；确认后点击「复制提示词」或「导出工作记录」。

## 使用说明

1. **描述需求。** 在「你希望改善什么？」中填写目标，可在下方输入框继续补充要求。当前预置示例展示 NPC 如何区分亲眼所见、他人告知和未知信息。
2. **编辑并保存。** 在「提示词草稿」中直接修改文字，填写可选的版本名称后保存。已保存的版本保持原样；每次保存都会新增一版。
3. **试写并查看。** 选择已保存的版本，填写试写场景，再点击「试写选中版本」。若草稿改动后尚未保存，先保存新版本。试写列表可查看各次正文及评价；当前正文固定展示伊恩与钥匙的两种反应。
4. **提交人工反馈。** 选择「达到预期」或「还需修改」，填写看法。需要引用时，在正文中选中片段并点击「引用选中正文」，或粘贴该正文中的文字，再点击「保存反馈」。
5. **继续修改。** 填写具体修改意见后点击「按反馈修改」。这会围绕所选试写对应的提示词版本载入下一版示例；保存新版本后才能继续试写。仅填反馈但未点击保存或修改的内容尚未保存。
6. **保留结果。** 「复制提示词」复制当前草稿；「导出工作记录」下载包含需求、草稿、讨论、版本、试写和反馈的 JSON 文件。页面会自动保存需求、草稿及已提交的记录，重新打开同一页面时尝试恢复。

准备示例期间可以点击「取消」。当前草稿和已有记录会保留；若这期间手动编辑了草稿，返回的建议会留在讨论中，供你查看后采用。

## 兼容性

使用启用 JavaScript 的现代浏览器，完整保留文件夹后可直接打开 `index.html`。当前尚未锁定浏览器最低版本；预览依赖浏览器的本地存储、结构化复制和随机标识能力。直接打开文件与界面交互尚待用户人工确认，可按「使用说明」体验；完成一轮后应保留两版提示词、各自的试写及人工反馈。

本地保存取决于浏览器是否允许当前页面使用存储。移动文件夹、换浏览器或清理浏览器数据后，已有记录可能无法恢复；需要留存时请导出工作记录。

## 常见问题（FAQ）

**为什么修改需求后，回复还是 NPC 与钥匙的例子？**

当前按钮用于演示预置流程，回复并非根据输入实时生成。你可以自由编辑草稿，并用版本、试写记录和反馈检查流程是否符合自己的使用习惯。

**为什么修改草稿后不能直接试写？**

请先保存为新版本，让这次试写准确对应修改后的提示词。

**页面提示保存失败怎么办？**

当前内存中的内容仍可编辑和导出。先点击「导出工作记录」留存；关闭页面前确认文件已下载。

**能导入此前导出的 JSON 吗？**

当前提供导出留存，尚未提供导入入口。
