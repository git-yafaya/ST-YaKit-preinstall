# ST-YaKit-preinstall

YaKit 系列的 SillyTavern 提示词试验台项目，计划通过独立试写与评分，帮助用户选出更符合角色扮演需求的提示词。

当前尚未发布可用版本。

## 功能特性（规划）

- 描述想改善的效果，获得多个可编辑的提示词版本。
- 用同一组场景比较不同版本，查看正文和具体扣分理由。
- 根据失败案例继续改进，并复制选中的提示词。

## 安装方法

尚无可安装版本，安装步骤将随首个可用版本提供。

## 使用说明（规划）

首个可用版本计划让你从一句需求开始，得到有试写结果可供比较的提示词。

1. 在 SillyTavern 中准备好模型连接配置。
2. 打开试验台，输入需求，并按需提供已有提示词。
3. 检查生成的测试场景和候选版本，开始试写。
4. 对照正文与评分理由，复制满意的版本或继续改进。

## 兼容性

最低支持版本将在接入验收后确定；首版计划使用 SillyTavern 的 Chat Completion 连接配置。
