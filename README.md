# ST-YaKit-preinstall

YaKit 系列的 SillyTavern 提示词工作台项目，计划帮助用户与 AI 一起设计和修改提示词，再用日常正文模型试写、由用户判断效果。

当前尚未发布可用版本。

## 功能特性（规划）

- 在工作台向 AI 描述需求，通过对话和手动编辑改进提示词。
- 选定提示词版本，使用平时的正文模型试写并亲自判断效果。
- 将正文中的问题片段和修改意见交回工作台 AI，得到下一版提示词。
- 保留各版提示词、试写正文和用户反馈，方便比较与选择。

## 安装方法

尚无可安装版本，安装步骤将随首个可用版本提供。

## 使用说明（规划）

首个可用版本计划让你从一句需求开始，通过试写和反馈得到满意的提示词。

1. 准备好日常正文模型连接，并为工作台选择模型连接配置。
2. 打开工作台，输入需求，并按需提供已有提示词。
3. 与工作台 AI 讨论、修改提示词，选定要试写的版本。
4. 使用平时的正文模型试写，阅读正文并判断是否符合预期。
5. 满意时复制提示词；需要调整时引用问题片段、说明期望，让工作台 AI 继续修改。

## 兼容性

最低支持版本将在接入验收后确定；首版计划使用 SillyTavern 的 Chat Completion 连接配置。
