# ST-YaKit-preinstall

YaKit 系列的 SillyTavern 提示词工作台，帮助你把写作需求变成提示词，通过正文试写和人工反馈逐版改进。

## 功能特性

- 从扩展菜单的「工作台」直接打开界面，关闭重开保留本次输入，页面顶部显示同款桌面与显示器图标及「预设工作台」标题。
- 与 AI 讨论需求，生成提示词，也能直接编辑草稿。
- 在「预设展示」集中查看当前预设的全部提示词条目，展开后直接修改并逐条保存，也可载入草稿继续改进。
- 按自定义提示词名称保存多个独立版本，名称后显示版本号，方便选择不同提示词复测；支持在版本记录中改名和删除。
- 使用当前聊天和主 API 试写正文，引用问题片段并交回修改。
- 每次试写保存当时的模型连接、提示词放置方式和聊天背景条件，可随工作记录导出。
- 为提示词设计选择主 API 或副 API，保存、切换多套连接，支持复用酒馆连接和拉取模型。
- 在设置中编辑内置提示词和破限提示词，确认后用于下一次提示词设计与修改。
- 通过常驻导航切换工作台、预设展示、试写与反馈、版本记录和设置，可选上方文字或下方图标，五页共用窗口尺寸并可分别滚动。
- 提供林系风、浅色、黑灰深色和跟随酒馆四种主题，窗口、按钮、下拉选项和滚动条同步配色。
- 手机端统一样式的下拉框支持再次点击收起列表。
- 复制、引用、刷新、跳转和展开入口统一显示为按钮，使用一致的悬停与按下反馈。
- 自动保存需求、草稿和已提交的记录，支持复制提示词、导出工作记录。
- 操作结果使用与纪实一致的底部轻提示，自动收起并跟随主题。
- 可单独打开本地演示，体验模拟生成、试写和反馈，演示记录单独保存。

## 安装方法

装好后可以在当前聊天中完成「生成提示词 → 保存版本 → 试写 → 反馈修改」；首次使用请先连接 SillyTavern 的主 API。

1. 将完整项目文件夹放入 SillyTavern 的 `public/scripts/extensions/third-party/` 目录，保留文件夹内的目录结构。
2. 刷新 SillyTavern，打开角色或群组聊天，从扩展菜单点击桌面与显示器图标旁的「工作台」。
3. 默认使用主 API；若要单独配置设计用模型，在「设置」展开「副 API」，点击「配置 API」，填写后保存。
4. 回到「工作台」，填写需求并点击「生成提示词」，将草稿「保存为版本」。
5. 进入「试写与反馈」，填写场景并点击「试写选中版本」，阅读正文后评价、填写意见，再点击「按反馈修改」。

### 本地演示

无需连接模型，即可用内置示例体验完整流程。

1. 在项目文件夹内启动静态服务，例如已安装 Python 时运行 `python3 -m http.server 8000`。
2. 打开[本地演示入口](http://127.0.0.1:8000/preview.html)，填写需求、保存版本并试写。
3. 阅读带有「本地演示」说明的示例正文，再提交反馈；演示记录保存在当前浏览器中，与酒馆记录分开。

## 使用说明

1. **描述需求。** 从扩展菜单打开「工作台」，在标题为「预设工作台」的窗口中填写「你希望改善什么？」，继续补充要求后点击「生成提示词」。修改讨论展示 AI 的说明，点击「查看提示词」按钮可展开完整建议；正常生成的提示词会进入草稿区。
2. **编辑并保存。** 在「工作台」直接修改草稿，填写提示词名称（如「第三人称叙事」）并点击「保存为版本」；不填写时显示「未命名提示词」。保存后保留名称，继续修改并保存会新增一版；在「版本记录」按名称和后面的版本号选择旧稿，再前往试写。
3. **试写并查看。** 进入「试写与反馈」，填写要检验的场景并点击「试写选中版本」。正文使用当前角色或群组聊天的背景和主 API；每次记录保留请求开始时的连接、提示词放置方式、聊天和背景设置。草稿改过后需要先回「工作台」保存新版本。
4. **提交反馈。** 选择「达到预期」或「还需修改」，填写具体意见。需要引用时选中正文并点击「引用选中正文」，或粘贴该正文里的片段。点击「保存反馈」可以先保留评价。
5. **按反馈修改。** 点击「按反馈修改」会保存当前反馈，再围绕这次试写对应的版本生成下一版。有引用时交回引用片段；未引用时交回该次完整正文。完成后点击「返回编辑」查看草稿，保存新版本后可以继续试写。
6. **保存成果。** 点击工作台中的「复制提示词」按钮复制当前草稿；点击版本记录中的「导出工作记录」按钮下载需求、草稿、讨论、版本、正文、反馈和试写条件。复制或导出后，底部短暂显示操作结果；遇到错误时显示红色提示。记录自动随酒馆设置保存；导出的文件不包含副 API 密钥。
7. **调整界面。** 在「设置」展开「界面设置」，选择林系风、浅色、深色或跟随酒馆，并选择导航位于上方或下方；选择后自动保存，五页同步生效。
8. **切页与退出。** 点击常驻页签切换页面，预设条目数和版本数显示在选择框旁；工作台随浏览器窗口自动调整大小。点击右上角关闭按钮、窗口外的遮罩或按 Esc 返回酒馆。需求、草稿和预设条目等输入继续保留；设置编辑页需先确认保存，返回、切页或关闭会放弃未保存的设置草稿。

9. **手机下拉选择。** 点击选择框展开列表，点击选项完成选择；暂时不选时，再次点击同一选择框即可收起。显示系统选单的浏览器按系统方式操作。

生成过程中可点击「取消」，已有内容会保留。主 API 请求可能仍需等待模型结束后才能再次发起；生成期间手动编辑的草稿不会被返回的建议覆盖。

### 管理提示词记录

1. 进入「版本记录」，选择要复测的提示词；页面显示它的名称、版本号、保存时间和原文。
2. 要改名时，编辑「提示词名称」并点击「保存名称」；名称会同步显示在工作台和对应的试写记录中，原文保持不变。
3. 要删除时，点击「删除提示词」，核对提示词名称、版本号及关联试写数量，再点击「确认删除」；也可点击「取消」保留记录。
4. 删除会同时移除该版本的试写和反馈，当前草稿继续保留。其余版本号保持不变，新保存的版本继续递增。

### 编辑预设条目

1. 点击导航中的「预设展示」；工作台默认读取酒馆当前使用的聊天补全预设，列出全部条目，也可切换到其他预设。
2. 点击条目名称按钮展开正文，直接修改后点击该条目的「保存条目」。可以同时编辑多条，逐条保存；标记条目仅供查看。
3. 需要 AI 帮助时，点击「载入草稿」进入工作台，载入的是已读取的原文；修改完成后点击「保存到原条目」，也可「保存为版本」留存。
4. 需要更新内容时点击「重新读取」，更新可选预设时点击「刷新列表」。切页、切换预设及重新读取都会保留本次工作台里尚未保存的编辑；刷新酒馆页面前请逐条保存。

保存只更新条目正文，保留名称、角色、开关、顺序及其他预设参数。若提示原文已变化，先处理酒馆中的改动，再「重新读取」，确认保留的编辑内容后保存。在「版本记录」选择旧版本或重新读取预设后，需要重新载入条目才能从草稿写回。

### 配置 API 与提示词

1. 打开「设置」，展开「副 API」，点击「配置 API」新建连接。
2. 选择酒馆的「连接配置文件」自动填写信息，或填写配置名称、Base url、API-Key 和模型名称；可点击「拉取模型」后从列表选择。
3. 点击顶栏「保存」后使用该副 API；在「使用配置」中切换，点击下方配置卡片可编辑或删除。选择「工作台 AI → 主 API」可恢复使用酒馆当前连接。
4. 展开「提示词」，进入「内置提示词」或「破限提示词」，编辑后点击顶栏「确认」。内置提示词负责引导设计，破限提示词作为补充要求一起发送。
5. 提示词偏离默认内容时显示「已修改」；点击「重置」只恢复编辑框的默认内容，确认后保存。返回、切换页面或关闭会放弃本次未确认的设置编辑。

读取酒馆连接完成后才能保存。酒馆不允许显示已保存密钥时，仍可复用该连接；填写自己的 API-Key 后可修改 Base url。正文试写继续使用主 API。

## 配置说明

| 设置 | 用法 |
| --- | --- |
| 界面主题 | 默认跟随酒馆，可切换林系风、浅色或深色；选择后立即保存 |
| 导航栏样式 | 默认上方文字，可切换下方图标；五页同步，选择后立即保存 |
| 工作台 AI | 负责提示词设计与修改，默认主 API，也可选择副 API |
| 使用配置 | 切换已保存的副 API；新增配置后自动选中，旧连接信息会保留为一项配置 |
| 连接配置文件 | 复用 SillyTavern 连接管理中的可用配置，也可单独覆盖模型名称 |
| Base url / API-Key | 独立 OpenAI 兼容接口的完整地址和密钥；需要认证的服务才需填写密钥 |
| 模型名称 | 可手动填写，也可拉取后选择；接口不支持模型列表时仍可手填 |
| 内置提示词 | 引导 AI 设计和修改提示词，重置后恢复初始内容 |
| 破限提示词 | 默认空白，作为内置提示词的补充，用于工作台的提示词设计和反馈修改 |
| 正文 AI | 始终使用当前主 API，在设置中显示当前类型 |

界面和 API 选择自动保存；连接编辑点击「保存」，提示词编辑点击「确认」。副 API 信息缺失或连接失效时会提示补全。密钥随酒馆设置保存；导出工作记录会排除全部副 API 密钥。

## 兼容性

最低支持 **SillyTavern 1.18.0**：本插件依赖该版本确认提供的独立生成、静默生成、连接请求和预设管理接口。真实模型请求和预设编辑通过酒馆扩展菜单打开；独立演示通过上面的本地入口打开。

支持自定义下拉样式的浏览器会显示统一配色、可换行的选项弹层；其他浏览器使用系统下拉菜单，外观由浏览器和系统决定。

当前版本已完成核心和适配器的本地检查；主 API、副 API 的真实模型调用及界面交互仍待人工验收。

## 常见问题（FAQ）

**为什么试写按钮不可用？**

先打开角色或群组聊天、连接主 API，再保存提示词版本；草稿与已保存版本不一致时需要另存新版本。

**试写会直接发到聊天里吗？**

试写正文显示在工作台，不会自动作为聊天消息发送。

**为什么点击取消后仍提示主 API 忙碌？**

取消后工作台会忽略迟到的结果；酒馆的主 API 请求可能还在运行，等它结束后再试。

**保存失败怎么办？**

先点击「导出工作记录」留存当前内容，确认下载完成后再关闭。未提交的反馈和设置仍需先保存。

**能导入记录或直接写回预设吗？**

可以在「预设展示」展开条目并点击「保存条目」写回，也可载入草稿修改后「保存到原条目」；工作记录支持导出，暂不支持导入。

**预设条目保存后会切换当前预设吗？**

不会。保存到当前使用的预设时，对应条目也会同步到酒馆；保存到其他预设时，当前选择保持不变。若目标条目已在酒馆中修改，请先处理那里的改动，再重新读取。

**为什么某些条目不能编辑？**

世界书、聊天记录等标记条目由酒馆填充，不提供正文编辑。目前读取已保存的 Chat Completion 预设；本地演示不连接酒馆预设。
