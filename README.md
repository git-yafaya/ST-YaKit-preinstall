# ST-YaKit-preinstall

YaKit 系列的 SillyTavern 提示词工作台，帮助你把写作需求变成提示词，用冲突场景、多份正文和 AI 盲评筛选效果，再按自己的喜好改进。

## 功能特性

- 从扩展菜单的「工作台」直接打开界面，关闭重开保留本次输入，页面顶部显示同款桌面与显示器图标及「预设工作台」标题。
- 每次新需求生成独立提示词，明确提出修改时才修订当前条目；替换草稿前自动保留未保存的原文，方便分别取用。
- 在「预设预览」查看全部条目，直接开关、展开编辑或载入草稿继续改进。
- 每条可独立选用原版或已保存的测试提示词，预览后应用到预设；保留原版，刷新后仍能切回。
- 按自定义提示词名称保存多个独立版本，名称后显示版本号，方便选择不同提示词复测；支持在版本记录中改名和删除。
- 自己填写固定场景，或让 AI 根据需求设计带有信息差、动机冲突和违规诱因的测试场景。
- 默认开启空卡模式，无需创建角色卡，只把测试提示词和场景交给正文模型；也可关闭后使用当前聊天。
- 一次测试默认生成三份独立样本；支持多次独立请求，或由支持的接口单次返回多份结果。
- AI 只根据原始需求、固定场景和匿名样本盲评，显示符合度、理由与违例，优先展示最高分样本；你仍可选择最喜欢的结果、引用片段并交回修改。
- 测试任务保存当时的需求、场景、版本、正文、评分和人工偏好，失败时保留已完成的样本，可重新盲评。
- 为提示词、场景、正文和裁判分别选择 API，保存多套连接、复用酒馆连接或拉取模型；提示词与场景可合并生成。
- 在设置中编辑内置提示词和破限提示词，确认后用于下一次提示词设计与修改。
- 通过常驻导航切换工作台、预设预览、试写与反馈、版本记录和设置，可选上方文字或下方图标，五页共用窗口尺寸并可分别滚动。
- 工作台在宽屏将需求与草稿均分为左右两栏，等高铺满可用区域；窄屏自动上下排列。
- 提供林系风、浅色、黑灰深色和跟随酒馆四种主题，窗口、按钮、下拉选项和滚动条同步配色。
- 手机端统一样式的下拉框支持再次点击收起列表。
- 复制、引用、刷新、跳转和展开入口统一显示为按钮，使用一致的悬停与按下反馈。
- 自动保存需求、草稿和已提交的记录，支持复制提示词、导出工作记录。
- 操作结果使用与纪实一致的底部轻提示，自动收起并跟随主题。
- 可单独打开本地演示，体验模拟生成、试写和反馈，演示记录单独保存。

## 安装方法

装好后可以完成「生成提示词 → 固定场景 → 三份样本 → AI 盲评 → 选择最喜欢的结果」；首次使用请先连接主 API，或配置各环节使用的副 API。

1. 将完整项目文件夹放入 SillyTavern 的 `public/scripts/extensions/third-party/` 目录，保留文件夹内的目录结构。
2. 刷新 SillyTavern，从扩展菜单点击「工作台」；默认空卡模式无需打开角色或群组聊天。
3. 默认使用主 API；使用其他连接时，在「设置 → 副 API」保存配置，再到「模块 API」为各环节选择连接。
4. 回到「工作台」，填写需求并点击「生成提示词」，将草稿「保存为版本」。
5. 进入「试写与反馈」，填写场景或选择 AI 场景，点击「创建测试任务」，等待三份样本及评分，再选择最喜欢的结果。

### 本地演示

无需连接模型，即可用内置示例体验完整流程。

1. 在项目文件夹内启动静态服务，例如已安装 Python 时运行 `python3 -m http.server 8000`。
2. 打开[本地演示入口](http://127.0.0.1:8000/preview.html)，填写需求、保存版本并试写。
3. 阅读带有「本地演示」说明的示例正文，再提交反馈；演示记录保存在当前浏览器中，与酒馆记录分开。

## 使用说明

1. **描述需求。** 从扩展菜单打开「工作台」，填写「你希望改善什么？」和本次要求，点击生成按钮。每次新要求默认生成一条独立提示词；需要调整当前条目时，明确写出要修改的内容，例如「把当前条目的动作描写改得更简短」。修改讨论展示 AI 的说明，点击「查看提示词」可展开建议；生成结果进入草稿区。
2. **编辑并保存。** 在「工作台」直接修改草稿，填写提示词名称（如「第三人称叙事」）并点击「保存为版本」；不填写时显示「未命名提示词」。保存后保留名称，继续修改并保存会新增一版；在「版本记录」按名称和后面的版本号选择旧稿，再前往试写。
3. **创建测试。** 在「你希望改善什么？」中写全本次评分要求，再进入「试写与反馈」。保留空卡模式，手填场景或选择「AI 生成冲突场景」，点击「创建测试任务」。工作台固定本次需求、提示词和场景，生成所选数量的样本后自动盲评；草稿改过后需要先保存新版本。
4. **筛选并反馈。** 默认先显示最高分样本，可在样本选择框查看其他正文、分数、理由和违例。点击「选为最喜欢」保留自己的判断；选择「达到预期」或「还需修改」，填写具体意见。需要引用时选中正文并点击「引用选中正文」，或粘贴该正文里的片段。点击「保存反馈」可以先保留评价。
5. **按反馈修改。** 点击「按反馈修改」会保存当前反馈，再围绕这次试写对应的版本生成下一版。有引用时交回引用片段；未引用时交回该次完整正文。完成后点击「返回编辑」查看草稿，保存新版本后可以继续试写。
6. **保存成果。** 点击工作台中的「复制提示词」按钮复制当前草稿；点击版本记录中的「导出工作记录」按钮下载需求、草稿、讨论、版本、测试任务、正文、评分、人工偏好、反馈和试写条件。复制或导出后，底部短暂显示操作结果；遇到错误时显示红色提示。记录自动随酒馆设置保存；导出的文件不包含副 API 密钥。
7. **调整界面。** 在「设置」展开「界面设置」，选择林系风、浅色、深色或跟随酒馆，并选择导航位于上方或下方；选择后自动保存，五页同步生效。
8. **切页与退出。** 点击常驻页签切换页面，预设条目数和版本数显示在选择框旁；工作台随浏览器窗口自动调整大小，宽屏的需求与草稿两栏等宽等高铺满可用区域，窄屏上下排列。点击右上角关闭按钮、窗口外的遮罩或按 Esc 返回酒馆。需求、草稿和预设条目等输入继续保留；设置编辑页需先确认保存，返回、切页或关闭会放弃未保存的设置草稿。

9. **手机下拉选择。** 点击选择框展开列表，点击选项完成选择；暂时不选时，再次点击同一选择框即可收起。显示系统选单的浏览器按系统方式操作。

生成过程中可点击「取消」，已有内容会保留。主 API 请求可能仍需等待模型结束后才能再次发起；生成期间手动编辑的草稿不会被返回的建议覆盖。

生成结果替换草稿前，尚未保存过的原文会自动留在「版本记录」，已保存过的相同原文不重复留存。要修改以前的条目，先在版本记录选择它，再回工作台说明修改要求。

### 场景与样本测试

1. **选择场景。** 「手动填写」使用你输入的文本，不能留空；「AI 生成冲突场景」可先点击「生成冲突场景」再编辑，也可留空，在创建任务时生成。已有场景会沿用，方便不同版本复测同一条件。
2. **选择背景。** 空卡模式默认开启，正文只使用提示词和场景，不加载角色卡、聊天、世界书、作者注释或酒馆预设。关闭后使用当前聊天背景，此时需打开角色或群组，并为正文选择主 API。
3. **选择样本数量。** 默认三份，可选一至六份。独立请求为每份样本发送相同输入，彼此不看其他样本；主 API 逐次请求，副 API 并行请求。
4. **选择单次生成。** 接口支持时，可选「单次请求返回 n 个样本」。接口必须实际返回所选数量；不支持时改用独立请求。文本补全和关闭空卡后的聊天试写使用独立请求。
5. **查看结果。** 创建后自动生成样本并盲评。裁判只看到工作台填写的原始需求、固定场景和随机编号的正文，不接收测试提示词、预设或设计讨论；分数为零至一百。任务中的「查看本次原始需求与固定场景」可核对本次条件。
6. **继续筛选。** 切换任务可看历史结果；旧版记录位于「历史单次试写」。裁判失败可「重新盲评现有样本」，正文和人工反馈继续保留；只生成部分样本时会明确标出数量。重评不会代替你的「最喜欢」选择。

### 管理提示词记录

1. 进入「版本记录」，选择要复测的提示词；页面显示它的名称、版本号、保存时间和原文。
2. 要改名时，编辑「提示词名称」并点击「保存名称」；名称会同步显示在工作台和对应的试写记录中，原文保持不变。
3. 要删除时，点击「删除提示词」，核对提示词名称、版本号及关联试写数量，再点击「确认删除」；也可点击「取消」保留记录。
4. 删除会同时移除该版本的测试任务、试写、评分和反馈，当前草稿继续保留。其余版本号保持不变，新保存的版本继续递增。

### 预览与搭配预设条目

1. 点击「预设预览」，读取酒馆当前已保存的聊天补全预设，也可在列表中选择其他预设。
2. 点击条目旁的「已开启／已关闭」按钮切换并保存状态；无需展开条目，酒馆允许切换的标记条目也可操作。
3. 展开条目，在来源列表选择「原版提示词」或已保存的测试版本；先查看正文，再点击「应用提示词」。各条目分别选择、分别应用，即可自由搭配；要在聊天中生效，还需开启该条目。需要新的测试提示词时，先在工作台「保存为版本」。
4. 想恢复时，选择「原版提示词」并应用。原文在首次应用测试版本时保留，刷新页面或删除测试版本后仍可恢复。
5. 原版正文可直接修改并「保存条目」；有未保存编辑时，先保存再应用其他版本。手动保存的正文会成为新的原版。点击「载入草稿」使用该条目当前已保存的正文，明确说明要修改当前条目后，可「保存到原条目」。
6. 点击「重新读取」更新内容，点击「刷新列表」更新可选预设。切页、切换预设和重新读取保留本次未保存编辑；刷新酒馆页面前请逐条保存。

应用与保存正文保留名称、角色、开关和原有位置；开关操作只改启用状态，首次开启未加入顺序的条目时，会按酒馆规则放到顺序开头。应用到当前预设会同步酒馆正常聊天，应用到其他预设不会切换当前选择。标记条目的正文由酒馆提供，不能替换或编辑。

若提示原文或开关已变化，先处理并保存酒馆中的改动，再「重新读取」。在「版本记录」选择旧版本或重新读取预设后，需要重新载入条目才能从草稿写回。

新生成的独立提示词保存在工作台中，可分别复制到酒馆预设。生成新条目或按试写反馈修订后，会解除原来的预设写回目标；目前工作台不提供新增酒馆预设条目的入口。

### 配置 API 与提示词

1. 打开「设置」，展开「副 API」，点击「配置 API」新建连接。
2. 选择酒馆的「连接配置文件」自动填写信息，或填写配置名称、Base url、API-Key 和模型名称；可点击「拉取模型」后从列表选择。
3. 点击顶栏「保存」后使用该副 API；在「使用配置」中切换，点击下方配置卡片可编辑或删除。选择「工作台 AI → 主 API」可恢复使用酒馆当前连接。
4. 展开「模块 API」，分别为提示词、冲突场景、正文样本和盲评选择主 API、已保存配置或「沿用工作台 AI」。
5. 需要提示词和场景同时生成时，先在试写页选择 AI 场景，再为这两个环节选同一连接，开启「生成提示词时，一次请求同时生成冲突场景」。手填场景会继续保留。
6. 展开「提示词」，进入「内置提示词」或「破限提示词」，编辑后点击顶栏「确认」。内置提示词负责引导设计，破限提示词作为补充要求一起发送。
7. 提示词偏离默认内容时显示「已修改」；点击「重置」只恢复编辑框的默认内容，确认后保存。返回、切换页面或关闭会放弃本次未确认的设置编辑。

读取酒馆连接完成后才能保存。酒馆不允许显示已保存密钥时，仍可复用该连接；填写自己的 API-Key 后可修改 Base url。正文样本使用「模块 API」中选择的连接；副 API 正文需要开启空卡模式。

## 配置说明

| 设置 | 用法 |
| --- | --- |
| 界面主题 | 默认跟随酒馆，可切换林系风、浅色或深色；选择后立即保存 |
| 导航栏样式 | 默认上方文字，可切换下方图标；五页同步，选择后立即保存 |
| 工作台 AI | 默认主 API；为选择「沿用工作台 AI」的环节提供连接，也可切换副 API |
| 使用配置 | 切换已保存的副 API；新增配置后自动选中，旧连接信息会保留为一项配置 |
| 连接配置文件 | 复用 SillyTavern 连接管理中的可用配置，也可单独覆盖模型名称 |
| Base url / API-Key | 独立 OpenAI 兼容接口的完整地址和密钥；需要认证的服务才需填写密钥 |
| 模型名称 | 可手动填写，也可拉取后选择；接口不支持模型列表时仍可手填 |
| 内置提示词 | 引导 AI 设计和修改提示词，重置后恢复初始内容 |
| 破限提示词 | 默认空白，作为内置提示词的补充，用于工作台的提示词设计和反馈修改 |
| 模块 API | 为提示词、场景、正文和盲评单独选择连接；正文默认主 API，其他环节默认沿用工作台 AI |
| 合并生成 | 默认关闭；AI 场景与提示词使用同一连接时可一次生成 |
| 空卡模式 | 默认开启；正文只使用候选提示词和固定场景 |
| 场景来源 | 默认手动填写，也可选 AI 生成冲突场景 |
| 独立样本数 | 默认三份，可选一至六份 |
| 样本请求方式 | 默认独立请求；支持的聊天补全接口可单次返回多份 |

界面和 API 选择自动保存；连接编辑点击「保存」，提示词编辑点击「确认」。副 API 信息缺失或连接失效时会提示补全。密钥随酒馆设置保存；导出工作记录会排除全部副 API 密钥。

## 兼容性

最低支持 **SillyTavern 1.18.0**：本插件依赖该版本确认提供的聊天补全与文本补全独立请求、静默生成、连接请求和预设管理接口。真实模型请求和预设编辑通过酒馆扩展菜单打开；独立演示通过上面的本地入口打开。

支持自定义下拉样式的浏览器会显示统一配色、可换行的选项弹层；其他浏览器使用系统下拉菜单，外观由浏览器和系统决定。

当前版本已完成核心和适配器的本地检查；主 API、副 API 的真实模型调用及界面交互仍待人工验收。

## 常见问题（FAQ）

**为什么试写按钮不可用？**

先填写原始需求并保存提示词版本；草稿与已保存版本不一致时需要另存新版本。空卡模式无需角色卡；关闭空卡时，才需要打开角色或群组并连接主 API。使用副 API 时要在「模块 API」为实际使用的各环节选择配置。

**为什么场景还在沿用聊天内容？**

在试写页打开「空卡模式」，正文请求只包含测试提示词和固定场景；关闭空卡时会继续加载当前聊天背景。可展开任务快照核对真正使用的场景。

**单次生成提示接口没有返回足够样本怎么办？**

将「样本请求方式」改为「独立请求」；该接口可能不支持一次返回多份结果。已生成的其他任务与评分会保留。

**试写会直接发到聊天里吗？**

试写正文显示在工作台，不会自动作为聊天消息发送。

**为什么点击取消后仍提示主 API 忙碌？**

取消后工作台会忽略迟到的结果；酒馆的主 API 请求可能还在运行，等它结束后再试。

**保存失败怎么办？**

先点击「导出工作记录」留存当前内容，确认下载完成后再关闭。未提交的反馈和设置仍需先保存。

**能导入记录或直接写回预设吗？**

可以在「预设预览」展开条目并点击「保存条目」写回，也可选择测试版本后「应用提示词」，或载入草稿修改后「保存到原条目」；工作记录支持导出，暂不支持导入。

**预设条目保存后会切换当前预设吗？**

不会。保存到当前使用的预设时，对应条目也会同步到酒馆；保存到其他预设时，当前选择保持不变。若目标条目已在酒馆中修改，请先处理那里的改动，再重新读取。

**为什么某些条目不能编辑？**

世界书、聊天记录等标记条目由酒馆填充，不提供正文编辑。目前读取已保存的 Chat Completion 预设；本地演示不连接酒馆预设。
