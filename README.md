# ST-YaKit-preinstall

YaKit 系列的 SillyTavern 提示词工作台，用同一场景对比多份提示词，并结合 AI 盲评与人工确认逐轮改进。

## 功能特性

- 按需求生成独立提示词，可直接输入数量同时生成多份，自动保存时按预设条目名称、编号和日期命名，支持继续修改、自动保留旧稿和多版本管理。
- 工作台左侧填写需求，右侧阅读修改讨论；每条提示词可展开查看、复制、保存为版本或写回原条目。
- 「版本记录」顶部集中选择、改名、删除和导出操作，改名与删除相关按钮大小统一，下方查看完整提示词。
- 从导航栏首项「预设预览」预览、开关和编辑预设条目，复制完整预设，搭配测试版本并随时恢复原版；细滚动条持续可见，聚焦条目或刷新列表时内容宽度保持稳定，在本页再次点击「预设预览」可回到顶部。
- 多选已保存的提示词，共用一个手填或按原始需求生成的测试场景；默认无需角色卡，每份提示词生成一份正文，也可各生成一至六份。
- 「试写与反馈」左侧顶部显示空卡或当前聊天状态，下方设置参数、填写场景，底部常驻「生成正文并比较」按钮；右侧切换任务、阅读正文与提交反馈，两区分别滚动，窄屏自动上下排列。
- 每篇正文对应一张对比卡片，显示来源提示词与版本，可同时阅读、比较评分，再选择样本填写反馈。
- AI 按原始需求盲评并排名，列出问题原句、对应要求和理由，区分明确违例与疑点。
- 选择最喜欢的样本，引用片段、保存反馈并据此修改提示词；失败后可重新盲评已有样本。
- 根据初审结果整合有效部分并进入二审；AI 终审后由你确认，仍需修改时重构提示词并开始下一轮。
- 为提示词、场景、正文和裁判分别选择副 API，留空时沿用酒馆当前 API；支持复用酒馆连接、保存多套配置和生成提示词后自动准备共用场景，配置页底部常驻操作按钮。
- 在「设置 → 内置提示词」集中调整提示词生成与修改、破限、补充、场景生成、裁判、反馈修订和聊天试写的引导，编辑页底部常驻返回、重置和确认；七项均提供内置引导，破限提示词随所有模型生成请求发送。
- 「设置」前提供「创意工坊」入口，目前显示「暂无内容」。
- 默认林系风提供暖纸白输入框、柔和细边框和鼠尾草绿聚焦光圈；四种主题可选，六页同步配色、窗口尺寸和动效，支持电脑与手机自适应布局。
- 「空卡模式」「生成提示词后准备共用场景」和「按 AI 分数排序」使用整块可点的选择卡片，点击时大小保持稳定，通过颜色提示选中状态。
- 自动保存需求、草稿和已提交记录，支持复制提示词、导出工作记录及独立本地演示。

## 安装方法

装好后可以完成「生成提示词 → 多选版本 → 同场景对比 → AI 盲评 → 人工确认」；首次使用请先连接酒馆 API，或配置副 API。

1. 将完整项目文件夹放入 SillyTavern 的 `public/scripts/extensions/third-party/` 目录，保留文件夹内的目录结构。
2. 刷新 SillyTavern，从扩展菜单点击「工作台」；默认空卡模式无需打开角色或群组聊天。
3. 副 API 留空即可使用酒馆当前 API；需要其他连接时，在「设置 → 副 API」保存配置，各环节默认沿用，也可在「模块 API」单独选择。
4. 回到「工作台」，填写需求和「生成数量」后点击「生成提示词」；在右侧修改讨论中保存单份结果，多份结果自动保存。
5. 进入「试写与反馈」，依次选提示词、填写或生成共用场景，点击「生成正文并比较」查看结果和评分。

### 本地演示

无需连接模型，即可用内置示例体验完整流程。

1. 在项目文件夹内启动静态服务，例如已安装 Python 时运行 `python3 -m http.server 8000`。
2. 打开[本地演示入口](http://127.0.0.1:8000/preview.html)，填写需求、保存版本并试写。
3. 阅读带有「本地演示」说明的示例正文，再提交反馈；演示记录保存在当前浏览器中，与酒馆记录分开。

## 使用说明

1. **描述需求。** 填写「你想要什么？」和本次要求，直接输入「生成数量」（默认 1，填写正整数），点击「生成提示词」。多份同时生成；新要求默认生成独立条目，要修改当前条目请明确写出修改内容。
2. **查看并保存。** 在右侧「修改讨论」展开对应结果的「查看提示词」，旁边可复制、保存到原条目或保存为版本。保存为版本会选中这条结果，可在「版本记录」改名；多份结果已自动分别保存，按条目名称、编号和日期命名，再次保存会新增版本。写回原条目需先载入来源，且该结果仍是当前修改稿。
3. **创建测试。** 在原始需求框写全评分要求，进入「试写与反馈」，在左侧按「选提示词 → 共用场景 → 生成并比较」依次勾选版本、准备场景，并设置「每份提示词生成正文数」，点击底部「生成正文并比较」。全部正文生成后统一盲评；勾选版本使用保存时的原文。
4. **筛选并反馈。** 在右侧切换测试任务，通过对比卡片阅读各份正文与评分，选中样本后向下核对详细评分并点击「选为最喜欢」，选择「达到预期」或「还需修改」并填写反馈。可在下方正文中选中片段点击「引用选中正文」，再「保存反馈」。窄屏时参数区在上，结果区在下。
5. **改进并复审。** 初审后可整合高分结果的有效部分，自动保存新提示词并在原场景进入二审；二审与终审均先看 AI 评分，再由你确认或提出修改。也可用单篇正文的「按反馈修改」生成草稿，保存后自行复测。
6. **保存成果。** 点击对应讨论结果旁的「复制提示词」，或在版本记录「导出工作记录」。已提交内容自动保存，导出不包含副 API 密钥。

生成过程中可点击「取消」，已有内容会保留。酒馆 API 请求可能仍需等待模型结束后才能再次发起；生成期间修改需求或切换版本后，返回的建议会保留在讨论中。

多份生成时，某份失败不影响其他结果保存；取消前已完成的提示词可在「版本记录」查看。「按反馈修改」每次仍只修订一份。

生成结果替换草稿前，尚未保存过的原文会自动留在「版本记录」，已保存过的相同原文不重复留存。要修改以前的条目，先在版本记录选择它，再回工作台说明修改要求。

多份结果及自动保留的旧稿统一按「预设条目名称-编号-YYYYMMDD」命名，例如「主提示词-3-20260911」。名称取本轮生成前载入的条目，未载入时使用「提示词」；编号持续递增，日期取保存当天的本地日期。

### 场景与样本测试

1. **选择场景。** 「手动填写」使用你输入的文本，不能留空；「AI 生成冲突场景」可先点击「生成共用场景」再编辑，也可留空，在创建任务时生成。AI 只根据原始需求构思，一次生成所有待测提示词共用的完整场景。已有场景会沿用，方便不同版本复测同一条件；修改需求后点击「生成共用场景」可重新生成。
2. **选择背景。** 点击「空卡模式」卡片切换开关，卡片通过颜色提示选中状态；默认开启，使用破限提示词、候选提示词和固定场景；关闭后使用当前聊天背景，需打开角色或群组，并让正文沿用酒馆当前 API（副 API 留空）。
3. **选择版本和数量。** 勾选一份或多份已保存提示词；默认每份生成一篇，可选每份一至六篇。例如两份提示词各三篇，共有六张对比卡。生成时逐张填入正文，历史任务保留创建时的数量。空卡模式下不同提示词和样本并行生成，各自使用对应提示词及同一场景；关闭空卡后的当前聊天试写逐次生成。
4. **选择单次生成。** 接口支持时，可选「每份提示词单次请求返回 n 份正文」。每份提示词各发起一次请求，输入相同场景，接口必须实际返回所选数量；不支持时改用独立请求。文本补全和关闭空卡后的聊天试写使用独立请求。
5. **查看结果。** 每张对比卡独立滚动查看完整正文，空间足够时并排展示，窄屏自动换行；未完成的样本保留空卡提示。裁判按原始需求、固定场景和匿名正文评分；补充要求需写入原始需求框。分数为零至一百分，允许并列；明确禁令优先，违例先看影响程度再看次数，疑点不直接按违规扣分。默认先显示最高分样本，点击「按 AI 分数排序」卡片可切换排序，样本编号保持不变；选中对比卡下方的按钮后，可继续查看详细评分并填写反馈。
6. **继续筛选。** 在结果区顶部切换任务可看历史结果，向下滚动查看正文、评分与反馈；旧版记录位于「历史单次试写」。裁判失败可「重新盲评现有样本」，正文和人工反馈继续保留；只生成部分样本时会明确标出数量。重评不会代替你的「最喜欢」选择。

生成失败或取消时保留原场景；生成期间修改需求、提示词或场景，返回结果不会覆盖本次编辑。固定场景会随测试任务保存和导出。

### 二审与终审

1. **整合初审结果。** 等全部正文和评分完成，阅读评分、明确违例与疑点，再到「整组评审」补充修改意见，点击「提取高分部分并试写」；AI 提取高分结果中有效的部分，保存完整新提示词，并沿用原需求和场景自动进入二审。
2. **确认二审。** 阅读二审的 AI 评分，点击「确认二审通过，进入终审」，系统会对同一批正文再次盲评，进入终审；这一步不重新生成正文。
3. **确认终审。** 阅读终审结果和「对比上一阶段评分」，点击「确认终审通过」；评分高低不会代替人工确认。
4. **继续修改。** 二审或终审仍不满意时，可填写意见，点击「拆分重构并重新初审」；AI 简述为什么没用、哪些地方没用、正确位置是什么，重构提示词并在同一场景开始下一轮初审。
5. **保留阶段记录。** 修订说明、评分和关联任务会保存；部分采样失败时先处理当前任务，取消后不会继续进入下一阶段。

### 管理提示词记录

1. 进入「版本记录」，在顶部按名称和版本号选择要复测的提示词，下方查看完整原文，再通过常驻导航进入「试写与反馈」创建测试。
2. 要改名时，编辑顶部的「提示词名称」，点击「导出工作记录」下方的「保存名称」；版本列表更新名称，历史测试保留当时的名称和原文。
3. 要删除时，点击同一区域的「删除提示词」，核对提示词名称、版本号及关联试写数量，再点击这组按钮下方的「确认删除」；也可点击「取消」保留记录。「保存名称」「删除提示词」「确认删除」「取消」四个按钮等宽等高。
4. 删除会同时移除包含该版本的整组对比任务、正文、评分和反馈；同组其他提示词版本仍保留，不相关任务继续保留。当前草稿不变，新保存的版本继续递增编号。

### 预览与搭配预设条目

1. 点击导航栏第一项「预设预览」（第二项为「工作台」），读取酒馆当前已保存的聊天补全预设，也可在列表中选择其他预设。
2. 想保留副本时，点击「备份预设」，复制当前预设已保存的全部内容，并在工作台和酒馆中切换到副本。名称从「原名-试作1」开始，接着当前最大试作编号递增；复制试作副本时继续沿用原名编号。需要带入本次编辑时，先保存对应条目。
3. 点击条目旁的「已开启／已关闭」按钮切换并保存状态；无需展开条目，酒馆允许切换的标记条目也可操作。
4. 展开条目，在来源列表选择「原版提示词」或已保存的测试版本；先查看正文，再点击「应用提示词」。各条目分别选择、分别应用，即可自由搭配；要在聊天中生效，还需开启该条目。需要新的测试提示词时，先在工作台「保存为版本」。
5. 想恢复时，选择「原版提示词」并应用。原文在首次应用测试版本时保留，刷新页面或删除测试版本后仍可恢复。
6. 原版正文可直接修改并「保存条目」；有未保存编辑时，先保存再应用其他版本。手动保存的正文会成为新的原版。点击「载入草稿」使用该条目当前已保存的正文，明确说明要修改当前条目后，可「保存到原条目」。
7. 点击「重新读取」更新内容，点击「刷新列表」更新可选预设；细滚动条持续可见，聚焦条目、移入移出鼠标和刷新列表时内容宽度不变。切页、切换预设和重新读取保留本次未保存编辑；刷新酒馆页面前请逐条保存。
8. 向下阅读后，再次点击当前「预设预览」导航项即可回到页面顶部，上方文字和下方图标导航均可使用。

应用与保存正文保留名称、角色、开关和原有位置；开关操作只改启用状态，首次开启未加入顺序的条目时，会按酒馆规则放到顺序开头。应用到当前预设会同步酒馆正常聊天，应用到其他预设不会切换当前选择。标记条目的正文由酒馆提供，不能替换或编辑。

若提示原文或开关已变化，先处理并保存酒馆中的改动，再「重新读取」。在「版本记录」选择旧版本或重新读取预设后，需要重新载入条目才能从草稿写回。

新生成的独立提示词保存在工作台中，可分别复制到酒馆预设。生成新条目或按试写反馈修订后，会解除原来的预设写回目标；目前工作台不提供新增酒馆预设条目的入口。

### 调整界面与退出

1. 打开「设置」，展开「界面设置」。
2. 默认使用林系风，已有主题选择继续保留；可选择林系风、浅色、深色或跟随酒馆，选择后六页立即同步并保存。林系风下各页的输入框与下拉框统一显示暖纸白底色，点击或用键盘聚焦时出现柔和绿光圈。
3. 导航选择「自动」时，PC 端显示上方文字，手机和平板显示下方图标；也可固定为「上方」或「下方」。
4. 点击「设置」前的「创意工坊」可进入该页，目前显示「暂无内容」；手机下拉列表可再次点击选择框收起，各页支持滚轮、触屏或键盘滚动。
5. 点击关闭按钮、窗口外的遮罩或按 Esc 退出；重开保留输入，未确认的设置草稿会丢弃。

### 配置 API 与提示词

1. 打开「设置」，展开「副 API」，点击「使用配置」右侧的「配置 API」新建连接。
2. 选择酒馆的「连接配置文件」自动填写信息；保存时未包含 API 类型的连接会沿用酒馆当前类型。也可填写配置名称、Base url、API-Key 和模型名称，点击「拉取模型」后从列表选择。
3. 点击页面底部右侧「保存」后使用该副 API；底部左侧「返回」放弃本次编辑，编辑已有配置时可点击同侧「删除」。在「使用配置」中切换，点击下方配置卡片可编辑；将选择留空即可沿用酒馆当前 API，已保存的配置会保留。
4. 展开「模块 API」，分别为提示词、冲突场景、正文样本和盲评选择已保存配置或沿用副 API；默认全部沿用，未填写副 API 时使用酒馆当前 API。
5. 需要生成提示词后自动准备场景，先在试写页选择 AI 场景，再开启「生成提示词后准备共用场景」。场景为空时，提示词生成成功后再按原始需求生成一个共用场景；两个环节可使用不同连接，已有场景继续沿用。
6. 展开「内置提示词」，选择要调整的引导，编辑后点击页面底部右侧「确认」。要调整根据「你想要什么？」生成提示词的方式，选择「提示词生成与修改提示词」；后续提示词生成和反馈修订都会使用保存的内容。破限提示词随所有模型生成请求发送，其余引导用于对应环节。已开始的任务继续使用开始时的内容；重新盲评使用最新保存的破限和裁判提示词。
7. 提示词偏离默认内容时显示「已修改」；点击底部左侧「重置」只恢复编辑框的默认内容，确认后保存。已有保存内容会继续保留；需要采用新版内置引导时，在对应提示词中重置并确认。返回、切换页面或关闭会放弃本次未确认的设置编辑。

读取酒馆连接完成后才能保存。酒馆不允许显示已保存密钥时，仍可复用该连接；填写自己的 API-Key 后可修改 Base url。正文样本使用「模块 API」中选择的连接；副 API 正文需要开启空卡模式。

## 配置说明

| 设置 | 用法 |
| --- | --- |
| 生成数量 | 工作台默认 1，填写正整数；多份同时生成并分别保存，数量自动保存，按反馈修改每次生成一份 |
| 界面主题 | 默认林系风，可切换浅色、深色或跟随酒馆；已有选择继续保留，选择后六页同步并立即保存 |
| 导航栏样式 | 默认自动：PC 端上方文字，手机和平板下方图标；可手动选择上方或下方，已有选择继续保留，六页同步并立即保存 |
| 使用配置 | 选择副 API，留空时沿用酒馆当前 API；新增配置后自动选中，旧连接信息会保留为一项配置 |
| 连接配置文件 | 复用 SillyTavern 连接管理中的可用配置，也可单独覆盖模型名称 |
| Base url / API-Key | 独立 OpenAI 兼容接口的完整地址和密钥；需要认证的服务才需填写密钥 |
| 模型名称 | 可手动填写，也可拉取后选择；接口不支持模型列表时仍可手填 |
| 内置提示词 | 下列七项均有默认引导，每项均可编辑、重置并确认保存；已有保存内容优先 |
| 破限提示词 | 随所有模型生成请求发送；默认使用叙事初始化文案，保留此前保存的内容，可重置并确认以应用默认值 |
| 提示词生成与修改提示词 | 指导 AI 根据本次需求生成独立提示词或修改指定条目；普通生成、多份生成和反馈修订共用 |
| 补充提示词 | 默认引导保留需求、约束与例外，精简重复并聚焦本次修改；用于设计和反馈修改，也可清空后确认 |
| 场景生成提示词 | 引导 AI 只以本次原始需求构思完整且可检验的共用场景；单独生成、创建任务时生成和提示词生成后准备场景共用 |
| 裁判提示词 | 引导需求拆解、逐篇审查和评分，用于初次评分与重评 |
| 反馈修订提示词 | 引导 AI 按用户提交的反馈修订对应版本 |
| 聊天试写提示词 | 关闭空卡时使用，引导当前聊天围绕本次场景生成 |
| 模块 API | 为提示词、场景、正文和盲评单独选择连接；场景连接一次生成完整场景，默认全部沿用副 API，未填写时使用酒馆当前 API |
| 生成提示词后准备共用场景 | 默认关闭；AI 场景为空时，在提示词生成后另行准备一次，可使用不同连接；按反馈修改不会触发 |
| 空卡模式 | 默认开启；正文使用破限提示词、候选提示词和固定场景 |
| 场景来源 | 默认手动填写，也可选 AI 生成冲突场景 |
| 待测提示词 | 可多选已保存版本，共用本次需求和场景 |
| 每份提示词生成正文数 | 默认一份，可选一至六份；总正文数为所选提示词数量乘以此数量 |
| 正文请求方式 | 默认独立请求；支持的聊天补全接口可单次返回多份 |

界面和 API 选择自动保存；连接编辑点击「保存」，提示词编辑点击「确认」。补充提示词可以留空，其余提示词清空后确认会恢复默认内容。副 API 连接信息全部留空时使用酒馆当前 API；只填写部分信息或所选连接失效时会提示补全。密钥随酒馆设置保存；导出工作记录会排除全部副 API 密钥。

## 常见问题（FAQ）

**为什么试写按钮不可用？**

先填写原始需求、保存提示词版本并勾选待测版本；勾选后使用已保存原文，想测试当前改稿时请先保存新版本。空卡模式无需角色卡；关闭空卡时，需要打开角色或群组，并让正文沿用已连接的酒馆 API。副 API 可在设置中统一选择，也可为各环节单独选择。

**为什么场景还在沿用聊天内容？**

在试写页打开「空卡模式」，正文请求包含破限提示词、测试提示词和固定场景；关闭空卡时会继续加载当前聊天背景。可展开任务快照核对真正使用的场景。

**单次生成提示接口没有返回足够样本怎么办？**

将「正文请求方式」改为「独立请求」；该接口可能不支持一次返回多份结果。已生成的其他任务与评分会保留。

**试写会直接发到聊天里吗？**

试写正文显示在工作台，不会自动作为聊天消息发送。

**为什么点击取消后仍提示酒馆 API 忙碌？**

关闭空卡后的聊天试写使用酒馆静默生成，取消后仍可能需要等待它结束；空卡独立请求会发送取消信号，工作台保留已收到的样本并忽略迟到结果。

**保存失败怎么办？**

先点击「导出工作记录」留存当前内容，确认下载完成后再关闭。未提交的反馈和设置仍需先保存。

**能导入记录或直接写回预设吗？**

可以在「预设预览」展开条目并点击「保存条目」写回，也可选择测试版本后「应用提示词」，或载入草稿修改后「保存到原条目」；工作记录支持导出，暂不支持导入。

**预设条目保存后会切换当前预设吗？**

不会。保存到当前使用的预设时，对应条目也会同步到酒馆；保存到其他预设时，当前选择保持不变。若目标条目已在酒馆中修改，请先处理那里的改动，再重新读取。

**为什么某些条目不能编辑？**

世界书、聊天记录等标记条目由酒馆填充，不提供正文编辑。目前读取已保存的 Chat Completion 预设；本地演示不连接酒馆预设。
